## Misc

### Some Helpful Definitions:

    Guidance:       involves the vehicle's current location and trajectory to a designated target, as well as desired 
                    changes in its velocity, rotation, and acceleration for following that path. [1]
    Navigation:     involves the vehicle's location and velocity (its state vector) and its attitude (angular
                    position in space). [1]
    Control:        involves the application of steering controls needed to execute guidance commands while maintaining
                    platform stability and smooth travel to target. [1]

[1] - [DSIAC, Introduction to Guidance, Navigation, and Control](https://dsiac.dtic.mil/technical-inquiries/notable/introduction-to-guidance-navigation-and-control-gnc/)
